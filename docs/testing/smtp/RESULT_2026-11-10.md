## Running the portal with SMTP

The normal local recording profile defaults to file-based mail. Use the
[session-only launcher](../../../scripts/smtp_session.py) to override it in memory:

```powershell
& 'C:/Users/91984/Downloads/online-exam-portal/.submission-demo/runtime/python311/python.exe' `
  scripts/smtp_session.py --user your-mailbox@gmail.com `
  --settings demo_settings `
  --settings-dir 'C:/Users/91984/Downloads/online-exam-portal/.submission-demo' `
  --database '<path-to-an-upgraded-local-demo-copy.sqlite3>' --with-ui
```

The local API listens on 127.0.0.1:8105 and the UI on localhost:5285. The helper
does not seed, reset or migrate an existing database. Use an upgraded disposable
copy; the original recording database stays preserved. It refuses unapplied
migrations and uses `--noreload` so a reloader cannot silently lose the in-memory
credentials. Enter the App Password when prompted; it is never a CLI argument.
Ctrl+C ends the session and its spawned UI process. Starting it again needs another
hidden password entry because no credential is persisted.

`--check` verifies effective SMTP settings without credentials, sending or starting
servers. The same helper can run `sendtestemail <controlled-recipient>` or the
project notification-worker commands. Start workers only for the intended fixture
recipients; the interactive server does not automatically start the outbox worker.
